Binary analysis and transformation

From executable bytes to analyzable program representations.

HydIR connects executable bytes to structured program representations and reproducible analysis artifacts. Examine disassembly and control flow, inspect LLVM IR and C output, explore symbolic behavior with Triton, and evaluate transformations against observed execution.

DocumentationTechnical articlesSource code

Analysis workflow

HydIR links recovered program facts, derived representations, and evaluation results to the binary under analysis. Addresses, machine bytes, analyst assertions, and generated artifacts remain available for inspection throughout the workflow.

Program recovery

Inspect ELF structure, symbols, instructions, control-flow graphs, call relationships, and effect summaries.

Semantic analysis

Examine lifted LLVM IR and C output. Use Triton expressions and path conditions to analyze relationships between inputs and results.

Transformation and evaluation

Generate patch and rebuild artifacts, compare their behavior with the original, and retain the associated reports.
