The HydIR project

What is HydIR?

HydIR is an open-source binary analysis and transformation workbench written in Rust. It connects executable bytes to Ghidra P-code, native intermediate representations, C views, and the evidence behind each result.

How HydIR works#

Start with one ELF. Follow static analysis, a recorded execution, or bounded symbolic exploration. Select a path to highlight its inputs and outputs.

Arrows indicate artifact or input dependencies. Trace, slice, and LLVM are alternative Ghidra operations. Native LLVM exports from FunctionIR; native C generation uses CIR. Frida witnesses one input-specific run; optional comparisons and rediscovery use validated Ghidra evidence. Triton operates on bounded machine-instruction paths, independently of LLVM and native C generation. A solver candidate needs separate concrete validation. Explore the full architecture.

Know what the output establishes#

HydIR keeps recovery, semantic fidelity, observed execution, and rewrite readiness separate. Unknown targets and opaque effects remain visible. Read the evidence and release gates alongside generated code.
