What a result means

HydIR records uncertainty beside its output. A recovered CFG can remain partial, an instruction can have a conservative effect, and a C view can preserve an opaque operation. Structural recovery, semantic modeling, execution comparison, and rewrite readiness are reported as separate claims. Read the guide to result status before treating an artifact as a proof.

Observe one path with Frida

The desktop has a top-level Frida observation tab that opens the Observe with Frida panel. On Linux x86-64 with the optional observer bundle, it can run a selected local ELF function against an InputSpec and record byte-checked blocks and calls for that input. See where to find the panel and how to read the observation.

Interfaces

The desktop workbench supports interactive analysis of a local ELF. The CLI produces artifacts for scripted workflows and controlled comparisons. A Python SDK offers local Ghidra operations; the authenticated service and SDK also expose revisioned project operations.
